## Diverifikasi BAIK (tidak perlu aksi — anti lapor ulang)
- **Reduced-motion**: ~20 blok `@media (prefers-reduced-motion: reduce)` di globals.css men-cover semua kelas animasi yang dipakai (anim-stagger/flame/xp-rise/pohon-*/treemark/ptr-spin/rt-check-ripple/pin-shake/dock/fab/hero-sheen/tree-heat/tree-bloom); ScrollReveal & CountUp guard via matchMedia; framer-motion tidak dipakai untuk gerak besar.
- **Touch target**: guard global `@media (pointer: coarse)` untuk `size-icon/size-sm/h-7/h-6/h-4`; kartu habit pakai checkbox/stepper h-10-h-11; dock 62px; FAB 56px; keypad PIN 56-64px.
- **Layout 320px**: grid `minmax(0,1fr)` + `> * { min-width: 0 }` (FIX-AUDIT-23), tabel desktop `overflow-x-auto` + hidden mobile, flex filter row `overflow-x-auto scrollbar-hide`, tx-date-pill flex-wrap, dock label mengecil <390px, zona FAB 20% ≥56px.
- **Dark mode**: warna kustom hampir selalu berpasangan `dark:`; kartu tree/pohon memang kartu gelap by-design (hex eksplisit konsisten light+dark); chart memakai `var(--chart-*)/var(--muted-foreground)` (FIX-COLOR-P3).
- **Cleanup**: semua setInterval/rAF/addEventListener yang ditemukan punya cleanup (today-hero, finance-today-card, pohon-screen+safeTimeout, work-desk, page-transition, count-up, money-particles, page.tsx drawer/menu/resize/matchMedia).
- **Empty/loading/error state**: hadir di semua daftar (habits, transactions, budgets, recurring, savings, catatan, tugas, board, goals, kalender, analisis, heatmap, pohon, asisten) termasuk kartu error + Coba Lagi pasca BUGHUNT-47/54.
- **Key/render**: `{count && …}` tak ditemukan pada angka (semua `> 0`/objek/null); key={i} tersisa hanya di skeleton & list statis; tidak ada `<img>` tanpa alt; tidak ada aria-label ganda; sonner themed via CSS var.
- **Z-index**: layering konsisten (dock 40 < sidebar 50 < lock 90 < splash 100; toast di atas semua).
